# कालिका देवी नवरात्रोत्सव २०२६ — डिजिटल आमंत्रण

श्री. कालिका देवी नवरात्र उत्सव मंडळ, पाटोदा यांच्यासाठी तयार केलेली मराठी, मोबाईलवर वापरण्यास सोपी स्थिर (static) वेबसाइट.

**Live:** https://prdpk.github.io/kalika-navratri-2026/

## यात काय आहे?
- कालिका देवीच्या छायाचित्रासह स्वागत पृष्ठ (मोबाईलवर पूर्ण रुंदीत, फोटो कापला जात नाही)
- नऊ माळांचे उपक्रम, सहभागी गट आणि प्रत्येक माळेचे आरतीचे मानकरी
- सर्व माळांच्या आरतीच्या मानकऱ्यांची एकत्रित यादी
- पारितोषिके, वेळ आणि स्थळाची माहिती
- मोबाईलवर थेट शेअर सुविधा; अन्यथा लिंक कॉपी करण्याचा पर्याय

## फाइल्स
| फाइल | काय आहे |
|---|---|
| `index.html` | पानाची रचना व स्थिर मजकूर |
| `data.js` | **नऊ माळांचे उपक्रम व आरतीचे मानकरी — नावे येथेच बदला** |
| `script.js` | माळ निवड, मेन्यू, शेअर — फक्त `data.js` मधील माहिती दाखवते |
| `styles.css` | डिझाइन (रंग, फॉन्ट, अंतर `:root` मध्ये एकत्र) |
| `assets/` | देवीचे छायाचित्र (JPEG + WebP, विविध आकार), favicon |

## आरतीचे मानकरी कसे बदलावे?
`data.js` उघडा. प्रत्येक माळेच्या `aarti:[...]` यादीत नावे लिहा:
- साधे नाव: `"संतोष लवांडे"`
- पदासह: `["राजुभैय्या जाधव","नगराध्यक्ष"]`
- नावे अजून ठरली नसल्यास यादी रिकामी ठेवा (`aarti:[]`) — वेबसाइटवर "लवकरच जाहीर होतील" दिसेल.

## संगणकावर पाहण्यासाठी
या फोल्डरमध्ये टर्मिनल उघडून:
```
python3 -m http.server 8000
```
आणि ब्राउझरमध्ये `http://localhost:8000` उघडा. (जुने पान दिसत असल्यास Cmd/Ctrl + Shift + R दाबा.)

## प्रकाशित (deploy) करण्यासाठी
GitHub Pages `gh-pages` branch वरून वेबसाइट प्रकाशित करते. या फोल्डरमधील git सेटअप एकाच `push` मध्ये `main` व `gh-pages` दोन्ही अपडेट करतो:
```
git add -A && git commit -m "Update" && git push
```
१–२ मिनिटांत https://prdpk.github.io/kalika-navratri-2026/ वर बदल दिसतील.

नवीन संगणकावर clone केल्यास हे एकदा चालवा, म्हणजे `git push` दोन्ही branches अपडेट करेल:
```
git config --add remote.origin.push refs/heads/main:refs/heads/main
git config --add remote.origin.push refs/heads/main:refs/heads/gh-pages
```

Firebase Hosting साठी `firebase.json` तयार आहे (`firebase deploy`).

## प्रकाशित करण्यापूर्वी तपासा
- माळांच्या स्वतंत्र तारखा दिलेल्या नाहीत; म्हणून उपक्रम क्रमांकानुसार दाखवले आहेत.
- आरतीच्या मानकऱ्यांची नावे हस्तलिखित यादीवरून घेतली आहेत — स्पेलिंग अधिकृतरीत्या तपासा.
- Google Fonts साठी इंटरनेट आवश्यक; ते लोड होईपर्यंत उपकरणावरील देवनागरी फॉन्ट वापरला जातो.
