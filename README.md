# कालिका देवी नवरात्रोत्सव २०२६ — डिजिटल आमंत्रण

श्री. कालिका देवी नवरात्र उत्सव मंडळ, पाटोदा यांच्यासाठी तयार केलेली मराठी, मोबाईलवर वापरण्यास सोपी स्थिर वेबसाइट.

## यात काय आहे?
- कालिका देवीच्या छायाचित्रासह स्वागत पृष्ठ
- नऊ माळांसाठी निवडता येणारी उपक्रम कार्डे
- प्रत्येक उपक्रमाचा सहभागी गट
- पारितोषिके, वेळ आणि स्थळाची माहिती
- मोबाईलवर उपलब्ध असल्यास थेट शेअर सुविधा; अन्यथा लिंक कॉपी करण्याचा पर्याय
- GitHub Pages किंवा Firebase Hosting वर प्रकाशित करण्यासाठी आवश्यक फाइल्स

## संगणकावर पाहण्यासाठी
या फोल्डरमधील `index.html` ब्राउझरमध्ये उघडा. किंवा Python उपलब्ध असल्यास या फोल्डरमध्ये `python -m http.server 8000` चालवा आणि `http://localhost:8000` उघडा.

## GitHub Pages वर प्रकाशित करण्यासाठी
1. GitHub वर `kalika-navratri-2026` नावाचे नवीन repository तयार करा.
2. ZIP फाइल उघडून त्यातील सर्व फाइल्स व `assets` फोल्डर repository च्या मुख्य स्तरावर अपलोड करा.
3. repository मधील **Settings → Pages** उघडा.
4. **Deploy from a branch** निवडा; branch `main` आणि folder `/(root)` निवडून Save करा.
5. प्रकाशित झालेला URL WhatsApp वर शेअर करा.

## Firebase Hosting वर प्रकाशित करण्यासाठी
1. Node.js आणि Firebase CLI इन्स्टॉल करा: `npm install -g firebase-tools`
2. या फोल्डरमध्ये टर्मिनल उघडून `firebase login` चालवा.
3. `firebase init hosting` चालवा आणि Firebase प्रकल्प निवडा. Public directory म्हणून `.` निवडा. `index.html` बदलण्यास विचारल्यास **No** निवडा.
4. या प्रकल्पातील `firebase.json` वापरा.
5. `firebase deploy` चालवा.
6. मिळालेला `web.app` किंवा `firebaseapp.com` URL WhatsApp वर शेअर करा.

## प्रकाशित करण्यापूर्वी तपासा
- माळांच्या स्वतंत्र तारखा दिलेल्या नाहीत; म्हणून वेबसाइटवर क्रमांकानुसार उपक्रम दाखवले आहेत.
- मंडळाचे नाव, स्थळाचे नाव आणि सहभागी गट अधिकृतरीत्या तपासा.
- Google Fonts साठी इंटरनेट कनेक्शन आवश्यक आहे; इंटरनेट नसल्यास उपकरणावरील पर्यायी फॉन्ट वापरला जाईल.
